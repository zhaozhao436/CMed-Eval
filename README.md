# CMed-Eval：面向大语言模型的系统性中文医学评测基准

**CMed-Eval: A Systematic Chinese Medical Benchmark for Evaluating Large Language Models**

CMed-Eval 从**显式知识挖掘、隐式知识运用和医学伦理**三个层次，系统评估大语言模型在中文医学场景中的能力。基准包含 **15 类任务、19 个子数据集和 215,152 条样本**，覆盖医学信息抽取、医学考试、知识问答、疾病诊疗、医学文献处理及伦理决策，并引入覆盖 **121 种罕见病**的诊疗场景。

## 研究动机

医学考试和知识问答能够反映模型的部分医学知识，但难以完整呈现其在结构化信息处理、复杂知识运用和伦理判断方面的能力。CMed-Eval 将这些能力纳入统一框架，通过细粒度任务评测，帮助识别模型的优势与不足，为中文医学大模型的针对性改进提供依据。

基准的主要特点包括：

- **系统的能力划分**：从文本中的知识挖掘，扩展到医学知识运用与伦理决策。
- **多样的任务形式**：兼顾结构化抽取、分类、选择题和开放式生成。
- **罕见病与常见病诊疗**：DTRC 包含 153 种疾病，其中包括 121 种罕见病和 32 种常见病。
- **多种评测设置**：比较零样本、少样本及指令微调后的表现，并结合自动指标、模型裁判与人工评价。

## 评测框架

| 评测层次 | 能力重点 | 任务编号 | 子数据集数 |
| --- | --- | --- | ---: |
| 显式知识挖掘 | 从医学文本中识别实体、抽取关系与属性 | CME1–CME3 | 5 |
| 隐式知识运用 | 运用医学知识完成理解、问答、诊疗及文献处理 | CME4–CME11 | 10 |
| 医学伦理 | 在医疗情境中作出符合伦理要求的回应 | CME12–CME15 | 4 |

其中，CME1、CME2、CME3 分别表示命名实体识别（NER）、关系抽取（RE）和属性抽取（AE）。同一个子数据集可以包含多个任务；关系抽取进一步区分模板输出与 JSON 输出（RE-json）。因此，**19 个子数据集在实验中展开为 25 个评测项**。

### 数据构建与质量控制

数据来源包括医学文献、疾病诊疗指南、医学教材、资格考试参考书、医学知识图谱及已有数据集。数据经过清洗、去重、术语规范化与任务切分，再通过三种方式构建。


## 实验设置

### 数据划分

| 数据划分 | 样本数 |
| --- | ---: |
| 训练集 | 195,153 |
| 验证集 | 12,000 |
| 测试集 | 7,999 |
| **总计** | **215,152** |

### 参评模型

论文评估了 9 个基础模型：

| 模型类别 | 模型 |
| --- | --- |
| 通用模型 | GPT-4、GPT-3.5、Baichuan2-13B-Chat、Qwen1.5-14B-Chat、ChatGLM3-6B、Llama 3-8B-Instruct |
| 医学领域模型 | ChatDoctor-7B、HuatuoGPT2-13B、Zhongjing-13B |

所有模型均在 **zero-shot、3-shot 和 5-shot** 设置下进行评测。此外，使用 CMed-Eval 训练集对 Baichuan2-13B-Chat 和 Qwen1.5-14B-Chat 进行 LoRA 监督微调，比较微调前后的表现。



### 评价方法

| 任务类型 | 评价方法 |
| --- | --- |
| 实体、关系与属性抽取 | Micro-F1 |
| 意图识别、术语标准化、阴阳性判断与医学考试 | Accuracy |
| 知识问答、诊疗、文献生成与翻译等生成任务 | BLEU |
| 医学伦理开放式回答的补充评价 | GPT-4o 模型裁判与人工评价 |

伦理回答的补充评价从**有用性、相关性和事实准确性**三个维度展开。人工评价从四个伦理子数据集中各分层抽取 30 条样本，共 120 条，每条由三名评价者独立评分，采用 10 分制：有用性 4 分、相关性 3 分、事实准确性 3 分。

不同任务使用不同指标，数值不能直接作为统一能力分数进行比较。BLEU 主要衡量与参考文本的词汇重合，不能单独代表诊疗正确性或伦理判断的完整性。

## 主要发现

1. **模型能力具有明显的任务差异。** 通用模型在任务覆盖与输出稳定性上整体更好，医学领域训练并不必然带来更强的指令遵循或结构化输出能力。
2. **少样本示例有助于理解任务与输出格式，但收益并非单调增加。** 在 DTRC 等知识密集型生成任务上，增加示例可能带来性能波动。
3. **指令微调的收益随任务层次发生变化。** 显式知识挖掘任务的提升最大，隐式知识运用任务次之，医学伦理任务的提升相对有限。
4. **微调收益也包含格式适配能力的改善。** 结构化抽取中的提升不能全部归因于新医学知识的获取；部分任务还存在微调后的局部退化。
5. **开放式回答需要多维评价。** 伦理任务中的 BLEU 排名与模型裁判、人工评价不完全一致，说明参考文本重合度与回答质量衡量的是不同方面。

上述结论对应论文中的参评模型与实验设置。
